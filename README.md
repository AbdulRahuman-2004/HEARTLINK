# 💜 HeartLink — Personalized Message Generator

HeartLink is a free, responsive website that helps users create personalized messages for love, birthdays, anniversaries, friendship, apologies, and other special moments.

Choose a relationship, occasion, language, and tone to generate a message that you can copy and share with someone special.

## ✨ Features

- 💕 Personalized love messages
- 🎂 Birthday and anniversary wishes
- 👫 Friendship and best-friend messages
- 💌 Sorry and missing-you messages
- 🌐 English, Tamil, and Tanglish support
- 🎨 Simple and responsive design
- 📋 Copy messages to the clipboard
- 🔄 Generate another message
- 📱 Works on mobile, tablet, and desktop

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
